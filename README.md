# 🎩 Oddjob

A dorm marketplace app for university students to make sharing items easier.
Submitted to Cornell Appdev's Hack Challenge and received award for Best Backend Design. 

## 👥 Features
- Sign in with your Google account to get started!
- Add your network of friends
- Share items you currently own and are willing to lend to friends
- See what your friends have available for you to end
- Send out requests for items you need
- Tracks trust scores for what users 

## 🛠️ Tech Stack
Frontend android app built with Jetback Compose with MVVM best practices. 
Backend server built with Express + MongoDB using Deno and deployed on Google Cloud Platform.
